Research spotlight

MetaBit: Quantization-Driven Metagenomic Analysis for Memory-Efficient High-Throughput Profiling

Mohammed Nayeem Uddin, Kamil Akhtar, Ritesh Yadav, Mohammed Alser · ALSER Research Lab

Metagenomic tools demand huge memory (NCBI RefSeq is ~4 TB; Kraken2 can use ~100 GB of RAM). MetaBit quantizes both reference genomes (FNA) and query reads (FASTQ) into fewer bits per base — a tool-independent way to shrink memory and speed up profiling.

8-bit → 4-bit→ 2-bit→ 1-bit3 quantization levels
  • 57×reduction in reference dataset size via a k-mer-based filtering methodology for CAMI benchmarks
  • 4×lower RefSeq storage with quantization
  • 2 toolsevaluated with Metalign and Kraken2 on CAMI_LOW and CAMI_HIGH
